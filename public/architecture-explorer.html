6 Lapisan Logis PostgreSQL 17 Multi-Tenancy
Layer 1: Klien, Pengguna & Perangkat Fisik
Direct Actors
Siswa (Role: siswa)

Pengisian LKS digital, pemantauan sensor kit meja, snapshot telemetri otomatis, rapor kompetensi.

/modules /reports
Guru (Role: guru)

Penjadwalan lab anti-tabrakan, penilaian LKS rubrik 4-skala, review snapshot telemetri, ekspor nilai.

/schedules /assessment
Superuser / Administrator

Pengelolaan multi-sekolah, peta persebaran wilayah GIS, registry lisensi LMS, rotasi API key fleet kit.

/master/regions /master/licenses
Trainer Kit (ESP32 Gateway)

Sensor 7-in-1 NPK pH EC Suhu Lengas Modbus RS-485 + 4 Relai Aktuator (Pompa, Valve, Fan, Light).

POST /api/v1/telemetry
Layer 2: Pintu Masuk, Keamanan & Fail-Closed Tenancy
Security Gate
Fail-Closed School Tenancy Anti-IDOR

Semua query di-scope ke school_id. Request tanpa relasi sekolah ditolak 403. Tidak ada kebocoran antar sekolah.

Strict Auth & Password Policy Hardened

Kewajiban ganti password login perdana (must_change_password). Zero backdoor password, proteksi brute-force.

Device API Key (SHA-256) Hardware Auth

Autentikasi hardware melalui header X-Device-Key, pencocokan hash SHA-256, rotasi atomik dan pelacakan last_used_at.

Layer 3: Single-Responsibility Actions & Domain Services
Clean Architecture
IngestTelemetryAction IoT Core

Memvalidasi payload sensor, tagging provenance hardware, clamping data, update last_seen_at, dan evaluasi anomali.

SchoolLicenseResolver Entitlement

Menghitung status hak akses berdasarkan interval term. Menangani edge-case gap renewal, partisi matematis disjoint terverifikasi.

CreateScheduleAction Academic

Penjadwalan lab praktikum dilindungi pessimistic lock PostgreSQL (FOR UPDATE), menolak bentrok waktu kit meja secara deterministik.

SubmitStudentReportAction LKS Digital

Menyimpan jawaban LKS ke riwayat append-only (student_report_attempts) dan membekukan snapshot telemetri sensor saat submit.

GradeStudentReportAction Penilaian

Penilaian rapor berbasis rubrik 4-skala Kurikulum Merdeka. Catatan revisi dan perubahan nilai tersimpan di report_grade_histories.

SchoolDistributionService GIS Wilayah

Drilldown 4-tingkat (Provinsi ➔ Kab/Kota ➔ Kecamatan ➔ Sekolah). Memisahkan koordinat tersimpan vs terverifikasi sebelum tampil di peta.

Layer 4: Penyimpanan Data PostgreSQL 17
Relational + JSONB
telemetry_readings
Composite Index: (device_id, recorded_at DESC)
student_reports
Append-only attempts & grade revision history
school_license_terms
Interval [start_date, expiration_date)
devices & keys
Fleet kit, JSONB relay state, SHA-256 hash
audit_logs
SQL Trigger: Tolak UPDATE/DELETE langsung

Simulator Alur Data Langkah-demi-Langkah

Pilih skenario operasional di bawah untuk melihat bagaimana data berpindah dari antarmuka, menembus lapisan keamanan, diproses oleh domain action, dan disimpan ke PostgreSQL.

             Struktur Tabel Kunci (PostgreSQL 17)
          

          
          

            

              

                telemetry_readings
                Time-Series
              

              
Menampung parameter 7-in-1: N, P, K, pH, EC, Suhu, Lengas, dan threshold_flags (JSONB).

              
Index: (device_id, recorded_at DESC)

            


            

              

                student_reports & attempts
                Append-Only
              

              
Menyimpan riwayat pengumpulan tugas siswa tanpa menimpa data lama. Dilengkapi snapshot telemetri sensor saat submit.

            


            

              

                devices & device_api_keys
                IoT Fleet
              

              
Menyimpan status trainer kit meja (`BITANIC-TK-01`..`06`), status relai (JSONB), offset kalibrasi, dan SHA-256 API key.

            


            

              

                school_licenses & terms
                Entitlements
              

              
Struktur lisensi berbasis interval tanggal. Menjamin partisi disjoint antara aktif, pending, dan kedaluwarsa.

            


            

              

                audit_logs
                Security Trigger
              

              
Dilindungi trigger native SQL di PostgreSQL: menolak eksekusi query UPDATE dan DELETE langsung.
